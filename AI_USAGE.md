# AI usage disclosure

AI tools were used during development as an assistant for analysis, implementation suggestions and technical writing. The project author made the final design decisions, reviewed the suggestions and integrated changes into the repository.

## Areas where AI assisted

| Area                          | How AI was used                                                                                                                                                                                         | Review boundary                                                                                                                                                                                      |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Code and security review      | Helped inspect authentication and authorization flows, public data exposure, input validation, rate limiting, logging and dependency vulnerabilities; suggested risks and mitigations for human review. | This was an assisted code review, not a penetration test, formal threat model or certification that the API is secure. Findings must be checked against the current code and deployment.             |
| API documentation and Swagger | Helped write endpoint descriptions and request, response and query examples, and compare them with the controller and DTO contracts.                                                                    | Examples should be exercised against the running API when a contract changes. The generated OpenAPI document remains the source to inspect for the actual current schema.                            |
| Architecture diagrams         | Helped map the current modules, runtime dependencies, registration and authentication flows into PNG/SVG diagrams, explanations and a local rendering script.                                           | Keep the diagrams aligned with the implementation; regenerate and visually review the images when the architecture or request flows change.                                                          |
| Tests                         | Helped identify missing cases, expand unit, end-to-end and integration coverage, and diagnose failing tests.                                                                                            | A suggested test is not evidence that it passed. Run the relevant command and review its output; coverage thresholds and test scopes are described in the root README.                               |
| DynamoDB                      | Helped reason about the table keys, product indexes, local DynamoDB setup, setup/seed scripts and integration-test behavior.                                                                            | Confirm table names, indexes, permissions and data lifecycle in the selected environment before using real data.                                                                                     |
| Terraform                     | Helped draft and review the DynamoDB infrastructure configuration, variables, safeguards, outputs and the setup/validation documentation.                                                               | Always inspect `terraform plan` for the intended AWS account, region and environment before applying. AI review does not replace AWS least-privilege review or a protected Terraform state workflow. |
